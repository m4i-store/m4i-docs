## إعادة الاختبارات محلياً

من فولدر **حزمة المراجعة**، بعد تجهيز Lua 5.4 وNode وPython:

```sh
find . -name '*.lua' -print0 | xargs -0 -n1 luac5.4 -p
lua5.4 tests/run.lua
node --test tests/web.test.mjs
python3 tests/contracts.py
```

على Windows استعمل بيئة تدعم هذه الأوامر أو نفذ فحص Lua لكل ملف على حدة. `tests/run.lua` يشغل اختبارات الخدمة التابعة أيضاً. لا تعلن نجاح CI البعيد اعتماداً على وجود workflow في ZIP؛ تحقق من run مرتبط بنفس commit.

## بوابة القبول داخل FiveM

سجل النتيجة وإصدار الحزمة وBridge وFXServer لكل مجموعة قبل production:

| المجموعة | ما يجب تجربته |
| --- | --- |
| التشغيل | جاهزية callbacks وSQL، الشخصية ورصيد الحسابين، وعدم التأثير على multicharacter. |
| الموديل | مورد واحد يوفر الملفات الستة، غياب duplicate YMAP، الخامات نهاراً وليلاً، السقف والتصادم والبيبان بالتفاعل والضو الخارجي. |
| الموظف | الإحداثيات والاتجاه، clipboard اختياري، مستوى القدمين، وأولوية E الموظف عند قربه من الباب. |
| الصلاحيات | رفض غير admin عند فتح/حفظ/حذف/نسخ/مراجعة الطلبات، وليس إخفاء الزر فقط. |
| Creator | manual vectors والكاميرا، 2 و10 مواقف، 1 و20 سيارة، تكرار model/ID، استيراد مستقل، تنظيف الأشباح والكاميرا بعد إلغاء ووفاة وتوقف المورد. |
| تنافس الإدارة | محاولة حفظ adminين بنفس revision؛ لا كتابة صامتة فوق تعديل أحدث. |
| الأداء | رصيد دقيق، حساب أول صفر، اقتطاع مختلط، مجموع ناقص، فشل الجزء الثاني، timeout وطلب مكرر وانقطاع وسط اقتطاع/رد. |
| السباون | مواقف ممتلئة وشراء لاعبين معاً، أبعاد كل model، عدم اقتطاع بلا موقف، تعويض فشل التسليم. |
| التسجيل | لوحة ولون صحيحان، مدة حقيقية، U، منع مفاتيح غير المالك، لا ملكية garage دائمة. |
| التجديد | كراء دقيقة وعشر دقائق، F6/F7، مدة لا تضيع عند الرفض، تجديد مرة واحدة، سعر كاتالوغ تغير وسيارة أزيلت منه. |
| الاسترجاع | حركة أمامية وخلفية، off-road وجسر وطريق بلا حافة، سائق آخر وركاب وNPC وراكب ميت وفقد network control. لا حذف أثناء الحركة أو بوجود راكب. |
| الإزالة | بدء 120 ثانية بعد التوقف والخلو، شفافية ثم حذف، وعدم دخول لاعب جديد خلال المهلة. |
| الاستمرارية | resource restart يتبنى العنصر مرة واحدة، full server restart يسمح pickup مرة واحدة دون أداء جديد، انتهاء الوقت أثناء الخروج، تغيير الشخصية. |
| الموارد الأخرى | ربط مفاتيح وMDT وgarage من APIs، ومنعهم من إعطاء صلاحية دائمة لسيارة كراء. |
| الأداء التقني | resmon قرب وبعد المكاتب ومع عدة عقود، عدم بقاء كاميرا أو loop بعد الإلغاء، وعدم تسرب عناصر الموظفين/الأبواب. |

المحاكاة لا تثبت حركة الذكاء الاصطناعي بجانب كل طريق. إيقاف المورد يوقف الإنفاذ مؤقتاً، لذلك يجب وجود إجراء صيانة للعقود النشيطة وليس ضماناً بأن توقيف السكريبت غير مؤثر.
