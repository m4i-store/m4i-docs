# m4i_rental — حل المشاكل

> ابدأ بتحديد [النسخة الفعلية](source-status.md). وجود اسم `m4i_rental` لا يعني أن أوامر ومخطط SQL لكل الفروع متطابقة.

## الأمر لا يعمل

إذا `/rentaladmin` غير موجود، راجع `fxmanifest.lua` وملفات `client/runtime.lua` و`server/rental.lua`. `main` الأساسي ليس نظام V4. الفرع الآخر يستعمل `/rentalcreator` وACE مختلفة، ولا يجوز خلط ملفاته مع حزمة المراجعة.

إذا ظهر `forbidden`، تحقق من `Config.Rental.adminAce` وعضوية principal الفعلية:

```cfg
add_ace group.admin m4i.rental.admin allow
```

هذا السطر يعطي الصلاحية للمجموعة، ولا يضيف حساباً إليها تلقائياً. لا تمنح صلاحية الإنشاء للجميع لحل مشكلة إعداد.

## المكتب موجود لكن الكراء غير متاح

الفرع الأول غير منشور وبلا مواقف أو كاتالوغ. أكمله من Creator: 2–10 مواقف و1–20 سيارة ثم نشر وحفظ. `site_unpublished` رفض شراء أو تجديد، وليس فشل تحميل الموديل.

تغيير `Config.Locations` بعد الزرع لا يغير SQL. عدّل الفرع المحفوظ، ولا تمسح KVP أو الجداول لإجبار الإحداثيات الجديدة. إذا الموظف مرتفع أو غارق، راجع موضعه و`clerkZOffset` داخل اللعبة؛ لا تطبق خصم متر آلياً.

## رسائل خدمة وأداء

| الرسالة | الفحص والإجراء |
| --- | --- |
| `service_starting` / `bridge_not_ready` | انتظر جاهزية Bridge وراجع ترتيب التشغيل وprovider. |
| `character_not_ready` / `character_changed` | اختر الشخصية الصحيحة؛ لا تكمل عرضاً صادراً لشخصية سابقة. |
| `money_unavailable` | تحقق من GetMoney وcapabilities لحسابات cash وbank. |
| `database_unavailable` / `schema_missing` | راجع SQL والمسار `sql/schema.sql` وصلاحيات الحساب. |
| `callback_registration_failed` | تحقق من نجاح RegisterCallback وعدم خلط نسخ المورد. |
| `visit_rental` | اقترب من موظف المحل الصحيح؛ مسارات المحل تتطلب bucket 0. |
| `parking_full` | أخل موقفاً مسجلاً أو صحح مواضع المواقف؛ لا تعيد checkout بلا توقف. |
| `quote_expired` | اطلب عرضاً جديداً؛ انتهى الوقت أو تغير revision/العقد. |
| `request_conflict` | نفس requestId استعمل مع token مختلف؛ لا تغير سجل العملية يدوياً. |
| `insufficient_funds` | المجموع الصحيح للكاش والبنك لا يكفي؛ التجديد لا يغير الموعد القديم. |
| `payment_pending` / `refund_pending` | افحص العملية الحالية قبل طلب آخر؛ الرد غير مؤكد بعد. |
| `payment_review` | طابق ledger واتبع [مسار المراجعة](payments.md). |
| `idempotency_required` | المزود لا يعلن منع التكرار المطلوب؛ لا تعطل الحماية دون فهم سياسة review. |
| `stale_revision` | أعد تحميل آخر نسخة من الفرع/العقد. |
| `site_has_leases` | عطل المبيعات وانتظر إنهاء العقود قبل حذف الفرع. |
| `already_spawned` | توجد سيارة مرتبطة؛ لا تنشئ نسخة ثانية لاستبدالها عشوائياً. |
| `lease_ending` | العقد في نهاية/استرجاع؛ انتظر الإزالة قبل فترة جديدة. |

## تشوه الخامات أو التعليق عند الدخول

لا يثبت ظهور الموديل بصورة سليمة في CodeWalker سلامة عرضه في FiveM، ولا تحدد صورة الخطأ وحدها سبب التعليق. ابدأ بعزل المورد على سيرفر اختبار، وراجع آخر F8 وCitizenFX log ونسخة artifacts وموارد الرسومات، ثم قارن بصمات الملفات الستة بالأساس المثبت.

لا تعاود تصدير YDR/YTD أو تخفض الدقة أو تمسح cache كعلاج مؤكد بلا دليل. لا تجمع V3 التجريبية القديمة مع النسخة المحولة التي نجحت عندك. V4 الموثقة تحفظ ملفات `stream` ولا تتضمن إصلاحاً جديداً لمحرك الخامات.

إذا استمر التعليق حتى بعد عزل المورد، اجمع سجل الكراش بدلاً من نسبته إلى الكراء تلقائياً. عند إرسال السجلات احذف tokens وبيانات الاتصال بـSQL والمعلومات الشخصية غير اللازمة.

## المفاتيح والـgarage

إذا المفتاح الخارجي يبقى صالحاً بعد النهاية، تحقق أن مورده يستعمل `HasRentalKeys` ولا يعتمد على key item دائم. `IsRentalPlate=true` يشمل التاريخ؛ لا يعني إذن القيادة. راجع [API](exports.md).

إذا السيارة المنتهية لا تحذف، تحقق من وجود ركاب أو حركة؛ التأخير مقصود عندما شرط التوقف والخلو غير محقق. افحص نقل network control ومسار الطريق والعميل السائق. لا تضف حذفاً فورياً لسيارة مشغولة لتجاوز المشكلة.

## معلومات مفيدة لطلب الدعم

حدد اسم الحزمة وبصمتها أو commit، وقت المشكلة، اسم الفرع والعقد/payment ID عند الحاجة، إصدار Bridge وprovider، رسالة F8/console، وطريقة إعادة المشكلة. بين هل تكررت بعد إعادة التشغيل أو تبديل الشخصية. لا ترسل بيانات الدخول أو مفاتيح API.

المصدر: رموز الأخطاء في `shared/domain.lua` و`server/bridge.lua` و`server/rental.lua` و`server/payment.lua` ضمن [لقطة المصدر](source-status.md).
